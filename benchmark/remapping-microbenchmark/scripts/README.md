# Remapping Benchmark Analysis Scripts

This directory contains scripts for analyzing and visualizing remapping benchmark results.

## Scripts

### analyze_results.py

Analyzes JSON results from benchmark runs and generates summary statistics.

```bash
# Analyze results in default directory (../results)
python analyze_results.py

# Analyze results from specific directory
python analyze_results.py /path/to/results
```

**Output:**
- `combined_results.csv` - Aggregated results in CSV format
- `analysis.json` - Detailed JSON analysis
- Console summary with cross-cloud comparison

### plot_results.py

Generates publication-quality plots from benchmark results.

```bash
# Generate plots (requires matplotlib, pandas)
pip install matplotlib pandas numpy
python plot_results.py

# Custom directories
python plot_results.py /path/to/results /path/to/output
```

**Generated Plots:**
- `cloud_comparison.png/pdf` - Latency comparison across AWS/GCP/Azure
- `throughput_comparison.png/pdf` - Throughput by cloud and format
- `latency_breakdown.png/pdf` - Read/Remap/Write time breakdown
- `format_comparison.png/pdf` - Position Deletes vs Deletion Vectors
- `scaling.png/pdf` - Latency vs number of deletes
- `latency_boxplots.png/pdf` - Distribution of latencies
- `summary_table.png` - Summary table as image

### monitor_benchmarks.sh

Real-time monitoring of running benchmarks across all clouds.

```bash
# Monitor with 30-second refresh (default)
./monitor_benchmarks.sh

# Custom refresh interval
./monitor_benchmarks.sh 10
```

### collect_and_cleanup.sh

Collects results from all clouds and terminates VMs.

```bash
./collect_and_cleanup.sh
```

**Actions:**
1. Collects results from AWS, GCP, Azure VMs
2. Terminates all benchmark VMs
3. Verifies no VMs are running

## Environment Variables

For cloud runner integration:

```bash
# AWS
export AWS_S3_BUCKET="iceberg-benchmark-xxx"
export AWS_SSH_KEY_NAME="iceberg-benchmark"
export AWS_REGION="us-west-2"

# GCP
export GCP_GCS_BUCKET="iceberg-benchmark-xxx"
export GCP_PROJECT="your-project"
export GCP_ZONE="us-central1-a"

# Azure
export AZURE_STORAGE_ACCOUNT="icebergbenchxxx"
export AZURE_STORAGE_CONTAINER="benchmark"
```

## Full Workflow

```bash
# 1. Run benchmarks (from cloud-runner directory)
cd benchmark/cloud-runner
./aws/run.sh all --config ../remapping-microbenchmark/configs/sigmod.yaml &
./gcp/run.sh all --config ../remapping-microbenchmark/configs/sigmod.yaml &
./azure/run.sh all --config ../remapping-microbenchmark/configs/sigmod.yaml &

# 2. Monitor progress
cd benchmark/remapping-microbenchmark/scripts
./monitor_benchmarks.sh

# 3. Collect and cleanup (after benchmarks complete)
./collect_and_cleanup.sh

# 4. Analyze results
python analyze_results.py

# 5. Generate plots
python plot_results.py
```
